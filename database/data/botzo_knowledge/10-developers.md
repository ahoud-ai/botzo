# المطورين والربط: API واتساب وAPI موتشي والـ Webhooks

## لمن هذا؟
للمبرمجين وأصحاب الأنظمة اللي يبون يربطون متجرهم أو تطبيقهم أو نظام الـ CRM مع بوتزو. الدليل الكامل مع الأمثلة: https://botzo.net/developers (عربي وإنجليزي).

## مفاتيح الـ API
- من لوحة التحكم ← أدوات المطورين ← مفاتيح الوصول. تكتب اسم للمفتاح وتختار صلاحيته، والمفتاح يظهر مرة وحدة بس، وينحفظ عندنا مشفّر.
- الصلاحيات:
  - **كل الصلاحيات**: كل الـ API.
  - **إرسال الرسائل فقط**: يرسل ويتابع حالة الرسائل، مناسب للمتاجر.
  - **قراءة فقط**: يقرا البيانات بدون ما يرسل أو يعدّل.
  - **موتشي فقط (للسيرفر)**: محادثات موتشي من سيرفرك.
  - **مفتاح موتشي العام (pk_)**: يتحط داخل تطبيق الجوال بأمان، لأنه ما يقدر إلا يفتح محادثات مع موتشي وبحدود لكل جهاز.
- المفتاح السري ما يتحط أبداً داخل تطبيق الجوال، لأن أي أحد يقدر يطلعه. تقدر تجدد أي مفتاح أو تلغيه في أي وقت.

## API إرسال رسائل واتساب
- إرسال نص، أو نص مع حتى 3 أزرار رد سريع، أو قالب معتمد بمتغيراته، أو صورة وفيديو وصوت وملف من رابط.
- كل رسالة ترجع رقم (message_id) تتابع فيه حالتها: أُرسلت، وصلت، انقرت، أو فشلت ومع السبب.
- لو واتساب رفضت الرسالة يرجع سبب واضح، مثل «مرت 24 ساعة على آخر رسالة من العميل» أو «اسم العرض لم يُعتمد» أو «مشكلة دفع في حساب Meta».
- **منع التكرار**: لو نظامك أعاد نفس الطلب بسبب النت، الرسالة ما تنرسل مرتين (Idempotency-Key).
- كل رسالة ترسلها من الـ API تظهر في صندوق الرسائل لفريقك.
- فيه كمان: إدارة جهات الاتصال والمجموعات، إنشاء حملات (الآن أو بموعد) بمتغيرات من بيانات كل عميل، عرض القوالب، والردود الآلية.

## API موتشي (المساعد الذكي داخل تطبيقك)
- تحط شات «اسأل موتشي» داخل تطبيق الجوال أو موقعك بتصميمك أنت، وموتشي يرد بنفس شخصية نشاطك ومعلوماته.
- الرد يرجع في نفس الطلب خلال ثواني، أو لاحقاً لو تبي.
- نفس المستخدم يكمل نفس المحادثة من أي جهاز.
- لو المستخدم طلب موظف، تتحول المحادثة لفريقك، ورد الموظف يوصل للتطبيق.
- المحادثات تظهر في صندوق الرسائل بعلامة «تطبيق: اسم التطبيق».
- يحتاج المساعد الذكي يكون مفعّل في حسابك.

## الـ Webhooks (إشعارات فورية لسيرفرك)
- من أدوات المطورين ← Webhooks: تحط رابط سيرفرك وتختار الأحداث، حتى 3 روابط.
- الأحداث: رسالة جديدة من عميل، تغيّر حالة رسالة، تحويل لموظف، ورد من موتشي أو موظف في محادثات الموقع والتطبيق.
- كل إشعار موقّع بسر خاص عشان سيرفرك يتأكد إنه من بوتزو.
- لو سيرفرك ما رد، بوتزو يعيد المحاولة تلقائياً (بعد دقيقة، 5 دقائق، 30 دقيقة، ساعتين).
- **المستقبِل التجريبي**: رابط جاهز داخل بوتزو تجرب عليه الإشعارات وتشوف شكلها قبل ما تكتب أي كود.
- سجل آخر الإشعارات ونتيجتها في لوحة التحكم.

## السرعة والحدود
- إرسال رسالة واتساب: غالباً أقل من ثانية ونص.
- رد موتشي: من ثانيتين لخمس ثواني.
- 120 طلب في الدقيقة لكل حساب، وحدود الباقة (عدد الرسائل وجهات الاتصال) تنطبق.

## هل يحتاج مبرمج؟
- الويدجت وموتشي في الموقع ما يحتاج برمجة: سطر كود واحد.
- الـ API والـ Webhooks يحتاجون مبرمج، والدليل فيه أمثلة جاهزة للنسخ بأكثر من لغة برمجة.
- فريق بوتزو يساعدك في الربط إذا احتجت: support@botzo.net
