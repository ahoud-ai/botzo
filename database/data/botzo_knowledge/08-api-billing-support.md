# API المطورين، الفواتير والدفع، والدعم الفني

## API للمطورين والربط مع الأنظمة
بوتزو يتربط مع أي نظام (متجر، CRM، نظام حجوزات، تطبيق جوال) بثلاث أدوات:
1. **API إرسال واتساب**: ترسل من نظامك رسالة نصية بأزرار، أو قالب معتمد، أو صورة وملف، وتتابع حالة كل رسالة (أُرسلت، وصلت، انقرت، فشلت)، مع منع الإرسال المكرر. وفيه كمان إدارة جهات الاتصال والمجموعات والحملات والقوالب والردود الآلية.
2. **API موتشي**: تحط المساعد الذكي داخل تطبيقك أو موقعك بتصميمك، والمحادثات تظهر في صندوق الرسائل وفريقك يقدر يرد منها.
3. **الـ Webhooks**: بوتزو يبلّغ سيرفرك لحظياً لما يوصل رد من العميل، أو تتغير حالة رسالة، أو يطلب العميل موظف، أو يرد موتشي أو موظف.

- المفاتيح من لوحة التحكم ← أدوات المطورين ← مفاتيح الوصول، ولكل مفتاح اسم وصلاحية (كل الصلاحيات، إرسال فقط، قراءة فقط، موتشي فقط، أو مفتاح موتشي العام للتطبيقات).
- **دليل المطورين الكامل بالعربي والإنجليزي** مع أمثلة جاهزة (JavaScript وPHP وPython وFlutter وSwift وKotlin): https://botzo.net/developers
- المرجع التفاعلي للطلبات: https://botzo.net/api-documentation
- استخدامات شائعة: إشعار تأكيد الطلب أو الشحن تلقائياً، تذكير المواعيد، أكواد التحقق بالقوالب، إضافة عملاء المتجر لجهات الاتصال، شات «اسأل موتشي» داخل التطبيق، وربط ردود العملاء بنظام الـ CRM.
- تفاصيل أكثر في ملف «المطورين والربط».

## الاشتراك والفواتير
- الاشتراك شهري أو سنوي، والسنوي أوفر.
- الدفع إلكترونياً عن طريق بوابة الدفع ميسر (Moyasar) بالبطاقات.
- الفواتير متاحة في لوحة التحكم ← الفواتير: عرض وطباعة وتحميل.
- كوبونات الخصم: تقدر تطبق كوبون عند الاشتراك إذا عندك واحد.
- الترقية لباقة أعلى أو التغيير لباقة ثانية من صفحة الاشتراك، والتغيير لباقة أقل يتجدول مع موعد التجديد.
- صفحة الاستهلاك توضح كم استخدمت من الرسائل وجهات الاتصال والردود الذكية مقارنة بحدود باقتك.

## إذا انتهى الاشتراك
- رسائل العملاء تفضل توصلك وتنحفظ في صندوق الرسائل، ما تضيع.
- الردود الآلية والمساعد الذكي يتوقفون لحين التجديد.

## الدعم الفني
- كل الباقات فيها دعم فني خلال أوقات العمل (الأحد إلى الخميس، 9 صباحاً حتى 5 مساءً)، وباقتي النمو والأعمال لها أولوية أعلى.
- تقدر تفتح تذكرة دعم من لوحة التحكم ← الدعم، وتتابع ردود الفريق فيها.
- أو تتواصل مباشرة: support@botzo.net أو 0557170022.
- كل باقة فيها جلسات تهيئة وتدريب مع الفريق.

## الأمان والخصوصية
- الربط رسمي عبر Meta.
- المفاتيح السرية (مثل مفتاح OpenAI الخاص بك أو بيانات الربط) تنحفظ مشفرة.
- الوسائط اللي يرسلها العملاء محمية ولا تفتح إلا لفريقك بعد تسجيل الدخول.
- صلاحيات الفريق تحدد مين يشوف إيش.
