# API المطورين، الفواتير والدفع، والدعم الفني

## API للمطورين
- تقدر تربط بوتزو بأنظمتك (متجرك، نظام الحجوزات، CRM) عن طريق API.
- من لوحة التحكم ← أدوات المطورين ← مفاتيح الوصول: تنشئ مفتاح (Access Token)، وتقدر تجدده أو تحذفه في أي وقت.
- أهم العمليات المتاحة:
  - إرسال رسالة نصية، أو رسالة قالب، أو وسائط لعميل.
  - إنشاء حملة.
  - إدارة جهات الاتصال (عرض، إضافة، تعديل، حذف).
  - إدارة مجموعات جهات الاتصال.
  - إدارة الردود الجاهزة.
  - عرض القوالب المعتمدة.
- التوثيق الكامل مع الأمثلة: https://botzo.net/api-documentation
- استخدامات شائعة: إرسال تأكيد الطلب أو تحديث الشحنة تلقائياً، تذكير المواعيد، إضافة العملاء من المتجر لجهات الاتصال.

## الاشتراك والفواتير
- الاشتراك شهري أو سنوي، والسنوي أوفر.
- الدفع إلكترونياً عن طريق بوابة الدفع ميسر (Moyasar) بالبطاقات.
- الفواتير متاحة في لوحة التحكم ← الفواتير: عرض وطباعة وتحميل.
- كوبونات الخصم: تقدر تطبق كوبون عند الاشتراك إذا عندك واحد.
- الترقية لباقة أعلى أو التغيير لباقة ثانية من صفحة الاشتراك، والتغيير لباقة أقل يتجدول مع موعد التجديد.
- صفحة الاستهلاك توضح كم استخدمت من الرسائل وجهات الاتصال والردود الذكية مقارنة بحدود باقتك.

## إذا انتهى الاشتراك
- رسائل العملاء تفضل توصلك وتنحفظ في صندوق الرسائل، ما تضيع.
- الردود الآلية والمساعد الذكي يتوقفون لحين التجديد.

## الدعم الفني
- كل الباقات فيها دعم فني خلال أوقات العمل (الأحد إلى الخميس، 9 صباحاً حتى 5 مساءً)، وباقتي النمو والأعمال لها أولوية أعلى.
- تقدر تفتح تذكرة دعم من لوحة التحكم ← الدعم، وتتابع ردود الفريق فيها.
- أو تتواصل مباشرة: support@botzo.net أو 0557170022.
- كل باقة فيها جلسات تهيئة وتدريب مع الفريق.

## الأمان والخصوصية
- الربط رسمي عبر Meta.
- المفاتيح السرية (مثل مفتاح OpenAI الخاص بك أو بيانات الربط) تنحفظ مشفرة.
- الوسائط اللي يرسلها العملاء محمية ولا تفتح إلا لفريقك بعد تسجيل الدخول.
- صلاحيات الفريق تحدد مين يشوف إيش.
